## الهدف
استبدال الإيصال الحالي بالقالب المرفق (ذهبي / كحلي / ورقي A4) مع الإبقاء على نفس عقد البيانات (`ReceiptData`) وضمان التزامن مع إعدادات الإصدار التي أنجزناها سابقاً (اسم AR/EN، س.ت، شعار، توقيع، عملة افتراضية).

## مصدر البيانات (مطابقة 1:1 مع القالب)

| عنصر في القالب | مصدره من `ReceiptData` / `BrandInfo` |
|---|---|
| شعار الرأس | `brand.logo` (data URL مضمَّن، يسقط على الأيقونة ⚜ عند غيابه) |
| اسم الشركة عربي | `brand.name` |
| اسم الشركة إنجليزي + س.ت | `brand.nameEn` · `س.ت {brand.crNumber}` |
| شارة الحالة | `statusKey/statusLabel` (أخضر PAID / أحمر OVERDUE / أصفر PARTIAL) |
| رقم الإيصال | `receiptNumber` |
| تاريخ الإصدار | `paymentDate` بصيغتين (هجري/ميلادي عربي + `08 Jun 2026` إنجليزي) |
| طريقة الدفع | `method` (AR + ترجمة EN قاموس صغير) |
| المستأجر | `tenantName` |
| المبنى — الوحدة | `building` — `unitNumber` |
| عن فترة الإيجار | `periodLabel` |
| شريط المبلغ الذهبي | `amount` بصيغة 3 خانات + `currency` (ر.ع/OMR، أو رمز العملة المختارة) |
| المبلغ كتابةً AR | `amountToWordsAr(amount, currency)` |
| المبلغ كتابةً EN | `amountToWordsEn(amount, currency)` |
| المتبقي | `cycleRemaining` (أخضر «مسدّد بالكامل» إن صفر، أحمر إن > 0) |
| التوقيع | `signatureDataUrl` (مضمَّن من Storage) |
| اسم الموقّع | `signatureName` أو `brand.landlordName · brand.landlordNameEn` |
| التذييل | نص ثابت ثنائي اللغة كما في القالب |

## التغييرات

### 1) `src/lib/pdfDocs.ts` — استبدال `buildReceiptHTML` (السطر 584 فقط)
- نسخ HTML/CSS القالب حرفياً مع:
  - استبدال خطوط `SF Arabic` بخطوطنا المضمَّنة `Noto Kufi Arabic` + `Outfit` (موجودة أصلاً في الملف عبر `inlinePdfFonts`).
  - حذف `.bar` و زر الطباعة (للـ PDF فقط).
  - إبقاء `@page{size:A4;margin:0}` و `.sheet { width:210mm; min-height:297mm }`.
- بناء الشارة ديناميكياً حسب `statusKey`:
  - paid → أخضر `#3C7A5A` · «● PAID · مدفوع»
  - partial → ذهبي · «● PARTIAL · جزئي»
  - late → أحمر `#B4503F` · «● OVERDUE · متأخر»
- شريط المبلغ: تنسيق رقم بـ 3 خانات للعملات الخليجية الثلاثية (OMR/BHD/KWD) وخانتين للباقي.
- صف المتبقي يُخفى إذا `cycleRemaining == null`.
- بلوك التوقيع يُخفى كاملاً إذا لا يوجد `signatureDataUrl`.
- الحفاظ على كل المعرّفات/الكلاسات حتى يخرج النص لاتينياً للأرقام وعربياً للنصوص (كما في القالب).

### 2) لا تغيير على
- `ReceiptData` / `BrandInfo` (الحقول كلها متوفرة من العمل السابق).
- نقاط الاستدعاء (`AddPaymentDialog`, `UnitDetail`, ...).
- `numberToWords.ts`, `signature.ts`, `brand.ts`, migrations.
- باقي قوالب PDF (عقد/كشف/تقرير) — خارج النطاق.

## خارج النطاق
- لا تغيير على منطق الدفعات أو الأرصدة.
- لا إضافة ختم (الطلب صريح: لا ختم).
- لا تعديل على نمط الواجهة داخل التطبيق — التغيير محصور بـ PDF.

## التحقق
بعد التطبيق: إصدار إيصال تجريبي من `AddPaymentDialog`، ومعاينة الـ PDF للتأكد من:
- مطابقة الألوان (`#272B3A` / `#B8924A` / `#FBFAF7`).
- ظهور الشعار + التوقيع كصور مضمَّنة.
- صحة «المبلغ كتابةً» بلغتين وثلاث خانات عشرية للعملة العمانية.

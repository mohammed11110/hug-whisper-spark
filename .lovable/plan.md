# خطة: رقم واتساب الأعمال للمشترك مع توثيق

## الهدف
السماح للمشترك بإضافة رقم واتساب رسمي لأعماله، التحقق من ملكيته بكود يُرسل عبر واتساب، وعرض شارة "موثّق" أو "غير موثّق" في كل مكان مناسب. الإرسال للمستأجرين يبقى عبر wa.me (مجاني).

---

## ما سيُبنى

### 1) قاعدة البيانات
إضافة حقول جديدة على جدول `profiles`:
- `business_whatsapp` — رقم واتساب الأعمال (E.164)
- `whatsapp_verified_at` — تاريخ التوثيق (null = غير موثّق)
- `whatsapp_verification_code` — كود مؤقت 6 أرقام (يُمسح بعد التحقق)
- `whatsapp_code_expires_at` — صلاحية الكود (10 دقائق)
- `whatsapp_verification_attempts` — عدد المحاولات (حد أقصى 5)

### 2) صفحة الإعدادات (`Settings.tsx`)
قسم جديد "رقم واتساب الأعمال":
- حقل إدخال الرقم مع code‑country picker
- زر "إرسال كود التحقق" → يولّد كود ويفتح wa.me لإرسال الكود لرقم المالك نفسه
- حقل إدخال الكود + زر "تأكيد"
- شارة الحالة: 🟢 موثّق / 🟡 بانتظار التحقق / ⚪ غير مضاف
- زر "تغيير الرقم" يعيد الدورة

### 3) Edge Function: `verify-whatsapp`
عمليتان:
- `request_code`: يولّد كود عشوائي 6 أرقام، يحفظه مع تاريخ انتهاء، يرجع الكود ليفتحه wa.me
- `verify_code`: يقارن الكود المُدخل بالمحفوظ (مع timing‑safe)، يضع `whatsapp_verified_at = now()`، يحذف الكود

### 4) عرض حالة التوثيق في كل مكان مناسب
- لوحة التحكم: شارة صغيرة بجانب اسم المشترك
- صفحة الإعدادات: قسم بارز
- مربعات إرسال WhatsApp (`AddPaymentDialog`، `UnitDetail`): إذا الرقم موثّق، يظهر "سيُرسل من رقمك الموثّق: +9665xxx"

### 5) ربط رقم الإرسال
عند فتح wa.me للمستأجرين، نضيف توقيع في نهاية الرسالة:
```
— من إدارة العقار، للتواصل: +9665xxxxxxx (واتساب موثّق ✅)
```
(الرقم يبقى رقم جوال المالك اللي ضغط الزر، لكن يظهر في الرسالة كمرجع للأعمال)

---

## الأمان
- التحقق من الكود يتم في Edge Function (مو في الواجهة) لمنع التلاعب
- حد محاولات: بعد 5 محاولات خاطئة، يلزم طلب كود جديد
- صلاحية الكود 10 دقائق فقط
- التحقق من صيغة الرقم E.164 بـ Zod في الواجهة والسيرفر

---

## التفاصيل التقنية

```text
المسار:
1. المشترك يدخل رقمه → "إرسال كود"
2. Edge Function يولّد "284913" ويحفظه
3. التطبيق يفتح wa.me/{رقم_المشترك}?text=كود التحقق: 284913
4. واتساب المشترك يستقبل الكود (لأنه يرسل لنفسه)
5. يدخل الكود → Edge Function يتحقق → ✅ موثّق
```

ملاحظة: في خطوة 3، wa.me يفتح محادثة المشترك مع نفسه — هذا سلوك مدعوم في واتساب. يقدر يرسل ويستقبل في نفس الجهاز.


# خطة: إخفاء الأشهر المدفوعة + تحسين الصياغة العربية

## 1) قائمة "شهر الإيجار" — إخفاء الأشهر المدفوعة

**الوضع الحالي (`src/components/AddPaymentDialog.tsx`):**
- عند وجود عقد نشط → القائمة تعرض فقط `unpaidMonths` (يعمل صح).
- إذا ضغط المستخدم "اختيار شهر آخر" أو لم يوجد عقد → يظهر fallback dropdown يعرض **كل** الـ 12 شهر بما فيها المدفوعة (هذا ما يظهر في الصورة).

**التعديل:**
- استبدال fallback بـ Select واحد ذكي يبني قائمة (year, month) ديناميكية:
  - يحسب آخر 24 شهراً + شهرين قادمَين.
  - يستثني أي شهر تم تحصيله بالكامل (`paid >= activeRent` أو `paid > 0` إذا لا يوجد عقد).
  - يُظهر بجانب كل شهر شارة صغيرة: "متبقّي 50.000" إن كان جزئياً.
- إذا لم يبقَ أي شهر غير مدفوع → بطاقة "كل الأشهر مُسدَّدة" مع رابط "إظهار جميع الأشهر" (escape hatch للحالات النادرة كالتعديل الرجعي).
- نفس المنطق يُطبَّق في `EditPaymentDialog.tsx` (حالياً يعرض كل الأشهر بدون فلترة).

**ملف الإنشاء/التعديل:** فقط `AddPaymentDialog.tsx` + `EditPaymentDialog.tsx`. لا تغييرات DB.

## 2) مراجعة الصياغة العربية

مرور سريع على الصفحات والمكوّنات الأكثر استخداماً لتصحيح الأخطاء الشائعة:

| الخطأ | التصحيح |
|---|---|
| "مرحبا" / "مرحبًا بك" غير المنسقة | "أهلاً بك" |
| "ادخل المبلغ" | "أدخل المبلغ" (همزة قطع) |
| "إختيار" | "اختيار" (همزة وصل) |
| "تم الحفظ بنجاح!" | "تم الحفظ" (بدون مبالغة) |
| "هل انت متأكد" | "هل أنت متأكد؟" |
| "اضافة" | "إضافة" |
| "الايجار" / "الايصال" | "الإيجار" / "الإيصال" |
| "متاخر" | "متأخر" |
| "العنوان" بدون نقطة في نهاية الجملة الكاملة | إضافة نقطة |
| استخدام "!" المتكرر | حذف ما عدا التهنئة |
| "Loading..." مترجمة كـ "تحميل..." | "جارٍ التحميل…" |
| "حذف نهائي" بدون تأكيد لغوي | "حذف نهائياً" |

**النطاق:** الملفات التالية فقط (الأعلى ظهوراً للمستخدم):
- `src/lib/i18n.tsx`, `src/lib/i18n2.tsx` (مصدر معظم النصوص)
- `src/pages/Dashboard.tsx`, `MonthlyCollection.tsx`, `Payments.tsx`, `Tenants.tsx`, `Buildings.tsx`, `Settings.tsx`, `Auth.tsx`, `Welcome.tsx`

لن أعدّل: ملفات edge functions، رسائل البريد، أو نصوصاً مرتبطة بالـ logic.

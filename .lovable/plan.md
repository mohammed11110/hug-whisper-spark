# خيار معاينة / حفظ لكل ملف يُنزَّل تلقائياً

حالياً عند الضغط على أي زر تنزيل في صفحة تفاصيل الوحدة، يبدأ التحميل مباشرةً دون معاينة. سنضيف نافذة معاينة موحَّدة تظهر قبل الحفظ، مع زرَّيْن: **حفظ** و **إلغاء** (للـ PDF يُضاف **طباعة**).

## الأزرار المشمولة (صفحة الوحدة)

| الزر | النوع | السلوك الجديد |
|------|-------|----------------|
| تنزيل العقد | PDF | معاينة + (حفظ / طباعة / إلغاء) |
| كشف حساب المستأجر PDF | PDF | معاينة + (حفظ / طباعة / إلغاء) |
| تصدير الدورات (CSV) | CSV | معاينة جدول + (حفظ / إلغاء) |
| تنزيل كشف الرصيد (CSV) | CSV | معاينة جدول + (حفظ / إلغاء) |
| طباعة العقد | طباعة | يبقى كما هو (هو معاينة طباعة أصلاً) |

## التنفيذ

**مكوّن جديد:** `src/components/FilePreviewDialog.tsx`
- يستقبل: `type: "pdf" | "csv"`, `title`, `content` (HTML للـ PDF أو صفوف للـ CSV), `filename`, `onSave`, `onPrint?`
- للـ PDF: يعرض الـ HTML داخل `<iframe srcDoc>` بارتفاع 70vh
- للـ CSV: يعرض جدول `<table>` قابل للتمرير مع شريط معلومات (عدد الصفوف، حجم تقريبي)
- الأزرار بالعربية: **حفظ الملف** • **طباعة** (PDF فقط) • **إلغاء**
- يحترم RTL والخط (Noto Kufi Arabic) ونظام الألوان (sage / cream)

**تعديل `src/pages/UnitDetail.tsx`:**
- استبدال الاستدعاءات المباشرة لـ `downloadHTMLAsPDF` / `downloadLeasePDF` / `exportToCSV` بفتح `FilePreviewDialog` مع المحتوى المُولَّد.
- إضافة state واحدة `previewState` تحمل بيانات الملف الحالي.
- زر **حفظ** ينفّذ نفس دالة التنزيل الحالية، زر **طباعة** يستعمل `printHTML` الموجود.

**المفردات العربية المستعملة:**
- "معاينة الملف" — عنوان النافذة
- "حفظ الملف" — زر التنزيل
- "طباعة" — زر الطباعة
- "إلغاء" — زر الإغلاق
- شريط CSV: "عدد الصفوف: X" • "الحجم التقريبي: X كيلوبايت"

## خارج النطاق
- لا تغيير على منطق توليد العقد أو الكشف.
- لا تغيير على قاعدة البيانات.
- صفحات أخرى تحتوي تنزيلات (إن وجدت لاحقاً) تُضاف بنفس المكوّن.

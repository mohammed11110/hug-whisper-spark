# تعديل: إظهار المتأخرات بوضوح عند تسجيل دفعة جديدة

## الهدف
عند فتح نافذة "تسجيل دفعة جديدة" واختيار المبنى ثم الوحدة:
1. إذا كانت الوحدة عليها متأخرات سابقة → إظهارها **بشكل بارز جداً** قبل إتمام الدفعة (تنبيه واضح، لا يمكن تجاهله).
2. في إيصال PDF → كتابة **المتبقي من إجمالي المتأخرات بعد خصم الدفعة الحالية** بشكل ظاهر.

---

## الوضع الحالي
ملف `src/components/AddPaymentDialog.tsx` يعرض حالياً:
- بطاقة "إجمالي المتأخرات حتى الشهر المحدد" (بلون burgundy خفيف) — موجودة لكن بسيطة وتأتي بعد حقل الشهر.
- بطاقة "تفاصيل المتأخرات" — تظهر فقط للأشهر السابقة (تستثني الشهر المختار)، بلون terracotta هادئ.
- الإيصال يطبع `arrearsUpToTotal` (الإجمالي **قبل** خصم الدفعة الحالية)، وقائمة `upTo` المحسوبة بعد الخصم.

المشكلة:
- التنبيه غير بارز كفاية — يضيع وسط بقية الحقول.
- الإيصال يكتب الإجمالي قبل الدفع وليس المتبقي بعدها (مربك للمستأجر).

---

## التغييرات — ملف واحد فقط
`src/components/AddPaymentDialog.tsx`

### 1) تنبيه بارز أعلى النافذة فور اختيار الوحدة
بطاقة تحذير قوية تظهر **مباشرة بعد حقل الوحدة وقبل حقل الشهر**، عند `unitId && unpaidMonths.length > 0`:

```
┌─────────────────────────────────────────┐
│ ⚠  هذه الوحدة عليها متأخرات              │
│                                          │
│    1,750.000 ر.ع                         │
│    موزعة على 3 أشهر غير مسددة            │
│                                          │
│    [ عرض التفاصيل ▾ ]                    │
└─────────────────────────────────────────┘
```

- الخلفية: `bg-burgundy/10` مع حد سميك `border-2 border-burgundy/40` و `rounded-2xl`.
- العنوان: أيقونة تحذير + نص bold بلون `text-burgundy`.
- المبلغ: حجم كبير (`text-2xl font-extrabold`) tabular-nums.
- زر "عرض التفاصيل" يكشف قائمة الأشهر داخل نفس البطاقة (collapsible).
- تظهر **مرة واحدة فقط** أعلى النافذة — نزيل البطاقة الحالية المكررة في الأسفل لتفادي التكرار.

### 2) دمج بطاقة "تفاصيل المتأخرات" داخل التنبيه البارز
الكشف عن قائمة الأشهر يصبح جزءاً من التنبيه (toggle)، بدل بطاقة منفصلة في الأسفل. الـ checkbox "تحصيل المتأخرات السابقة مع هذه الدفعة" يبقى في مكانه الحالي.

### 3) تحديث الإيصال — إظهار المتبقي بعد الدفع
في استدعاء `buildReceiptHTML`:
- `unpaidTotal` يصبح **مجموع `upTo` بعد الخصم** بدل `arrearsUpToTotal` (الإجمالي قبل الدفع).
- إضافة تسمية واضحة: "المتبقي من المتأخرات بعد هذه الدفعة" (نمرر `unpaidUpToLabel` معدّل أو نعتمد على المنطق الحالي).

```ts
// قبل
unpaidTotal: includeArrears ? arrearsUpToTotal : 0,

// بعد  
unpaidTotal: includeArrears ? unpaidTotal : 0,  // unpaidTotal = sum(upTo) بعد الخصم
```

### 4) إخفاء البطاقة القديمة الموجودة (السطور 547-563)
نزيلها لأن التنبيه الجديد في الأعلى يحل محلها بشكل أفضل.

## ما لن يتغير
- لا تعديل على قاعدة البيانات.
- لا تعديل على `pdfDocs.ts` (الحقول كافية).
- لا تعديل على منطق الحفظ ولا عدد الصفوف المُدخلة.
- صفحة المدفوعات الرئيسية تبقى كما هي.
- الـ checkbox "تحصيل المتأخرات السابقة" يبقى بدون تغيير.

---

## النتيجة المتوقعة
- المستخدم **لن يستطيع تجاهل** المتأخرات — تظهر فوراً بشكل بصري قوي.
- الإيصال يوضح للمستأجر: "لقد دفعت X، ومتبقي عليك Y من المتأخرات".

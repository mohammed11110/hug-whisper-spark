
# خطة: ترقية صفحة الإعدادات بالكامل

العمل كلّه في `src/pages/Settings.tsx` بشكل أساسي، مع تعديلات صغيرة على `src/lib/appSettings.tsx` و `src/lib/i18n2.tsx` فقط للمفاتيح الجديدة. لا تغييرات على المنطق التجاري ولا على قاعدة البيانات.

---

## أولاً: الحذف (تنظيف)

1. **زر "المساعد الذكي العائم"** (`showAiFab`) — يُحذف من واجهة الإعدادات (يبقى الحقل في `AppSettings` افتراضياً `false` للتوافق مع باقي الكود).
2. **"مدة حفظ الفلاتر"** (`filterRetentionMin`) — يُحذف القسم كلياً من الواجهة، تبقى القيمة الافتراضية `-1` (احتفاظ دائم).
3. **الهوامش الأربعة المنفصلة** (`margins.top/right/bottom/left`) — تُستبدل بهامش موحّد ثابت 16mm. يُحذف القسم بالكامل.
4. **قسم "إعدادات متقدمة"** كقسم مستقل — يُدمج ما يبقى منه داخل تبويب "الطباعة".
5. **قائمة العملات الطويلة المسطّحة** — تنتقل إلى Sheet منفصل يفتح عند الضغط على بطاقة العملة.
6. **حقلَي `prefix` + `padding` المنفصلَين للإيصالات** — يُدمجان في حقل واحد مع معاينة حيّة (مثال: `R-00001`).

## ثانياً: الهيكل الجديد — 5 تبويبات

```text
┌─────────────────────────────────────────────┐
│  بطاقة الحساب (Avatar + الاسم + الخطة + ⚙)  │
│  ✓ يتم الحفظ تلقائياً                        │
├─────────────────────────────────────────────┤
│ [الحساب] [الهوية] [التنبيهات] [الطباعة] [...] │
└─────────────────────────────────────────────┘
```

### تبويب 1 — الحساب
- بطاقة موحّدة: Avatar + الاسم + البريد + شارة الخطة + زر "إدارة الاشتراك".
- اللغة (نفس الشكل الحالي بشكل مضغوط).
- العملة: بطاقة واحدة تعرض العملة الحالية، الضغط يفتح Sheet للاختيار من بين 30+.
- المنطقة الزمنية (إن وُجدت).
- حذف الحساب (يبقى).

### تبويب 2 — الهوية (Brand)
- **Drag & Drop للشعار** مع معاينة دائرية (بديل عن FileUpload الحالي).
- اسم العمل، رقم الهاتف، العنوان، اسم المالك (AR/EN).
- **معاينة حيّة للإيصال** على اليسار/تحت تتحدّث فوراً مع كل تغيير.

### تبويب 3 — التنبيهات
- أيام التنبيه المسبق للدفع (`upcomingDays`).
- أيام تحذير انتهاء العقد (`contractWarnDays`).
- ألوان الحالات (paid/late/soon) — تبقى كما هي بشكل مضغوط.

### تبويب 4 — الطباعة والإيصالات
- حجم الصفحة: A4 / A5 / Letter (3 أزرار بصرية).
- **رقم الإيصال**: حقل واحد مع dropdown للبادئة الشائعة (`R-`, `INV-`, مخصّص) + slider للأرقام (1-6) + **معاينة حيّة**: `R-00001`.
- قوالب الواتساب الثلاثة (reminder/late/receipt):
  - **شارات قابلة للنقر** لإدراج المتغيرات: `{tenant}` `{unit}` `{building}` `{amount}` `{remaining}` `{month}`.
  - زر **"اختبار"** لكل قالب يفتح حواراً صغيراً بمعاينة الرسالة ببيانات وهمية.

### تبويب 5 — الأمان والمتقدّم
- **PIN على شكل OTP** (4 خانات منفصلة باستخدام `InputOTP` المتوفّر).
- **تصدير/استيراد الإعدادات** (JSON download/upload).
- زر إعادة الضبط للقيم الافتراضية.

## ثالثاً: تحسينات شاملة

- **شريط أعلى ثابت**: "✓ يتم الحفظ تلقائياً" بدل toast لكل تغيير. Toast يظهر فقط للأخطاء أو العمليات الكبيرة (تصدير، إعادة ضبط).
- **بطاقات بحواف sage** وظلال خفيفة بدل الحدود الثقيلة.
- **عناوين أقسام مع أيقونات** صغيرة (User, Palette, Bell, Printer, Shield).
- **RTL/LTR** محترم بالكامل، الترجمات تُضاف لـ `i18n2`.

## ملاحظات تقنية

- `AppSettings` في `appSettings.tsx`: الحقول `showAiFab` و`filterRetentionMin` و`margins` تبقى موجودة في الـ type للتوافق، لكن لا تظهر في الواجهة. الهامش يُحسب من `16mm` ثابت عند الطباعة.
- مكوّنات جديدة داخلية في `Settings.tsx` فقط (لا ملفات جديدة عدا إذا تجاوز الحجم):
  - `AccountCard`, `CurrencySheet`, `ReceiptPreview`, `ReceiptNumberBuilder`, `TemplateEditor` (مع chips + اختبار), `PinOtpInput`, `SettingsImportExport`.
- استخدام `InputOTP` الموجود في `src/components/ui/input-otp.tsx` للـ PIN.
- لا مكتبات جديدة. Drag & Drop عبر HTML5 native (`onDragOver`/`onDrop`).
- استخدام tokens فقط: `sage-*`, `gold` (للخطة المدفوعة)، `terracotta` (للتحذير)، `burgundy` (للحذف).

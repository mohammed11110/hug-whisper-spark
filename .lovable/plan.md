## المطلوب
عند فتح "تسجيل دفعة جديدة" واختيار المبنى والمستأجر وشهر الدفعة:
1. عرض **إجمالي المتأخرات حتى الشهر المحدد** (شامل) بشكل واضح داخل النافذة.
2. طباعة هذا الإجمالي في إيصال PDF.

## التغييرات — ملف واحد فقط
`src/components/AddPaymentDialog.tsx`

### 1) حساب جديد: متأخرات حتى الشهر المحدد
بعد سطر `priorArrearsTotal` نضيف:
```ts
const arrearsUpToSelected = unpaidMonths.filter(
  (m) => m.year < periodYear || (m.year === periodYear && m.month <= periodMonthNum)
);
const arrearsUpToTotal = arrearsUpToSelected.reduce((s, m) => s + m.remaining, 0);
```
(هذا يشمل المبلغ المستحق عن الشهر المختار + كل الأشهر الأقدم غير المسددة).

### 2) عرض البطاقة في الواجهة
بعد اختيار المبنى والوحدة (المستأجر)، تظهر بطاقة موجزة فوق حقل المبلغ:

```
┌─────────────────────────────────────────┐
│  إجمالي المتأخرات حتى [مايو 2026]       │
│  1,250.000 ر.ع                          │
│  (3 أشهر غير مسددة)                     │
└─────────────────────────────────────────┘
```

- تختفي البطاقة إذا كان `arrearsUpToTotal = 0` أو لا توجد وحدة مختارة.
- تستخدم ألوان النظام: خلفية `bg-burgundy/10`، حدود `border-burgundy/20`، نص `text-burgundy`.
- العنوان يتغير ديناميكياً مع تغيير الشهر/السنة.

### 3) عرض في الإيصال (PDF)
في استدعاء `buildReceiptHTML` نمرّر القيمتين الجديدتين كحقول إضافية (نفس آلية `unpaidTotal` الموجودة). الحقل `unpaidTotal` و `unpaidUpToLabel` موجودان فعلاً — سنتأكد فقط أن القيمة المُمرّرة هي **الإجمالي حتى الشهر المختار قبل خصم الدفعة الحالية** بدلاً من الإجمالي بعد الخصم، حتى يرى المستأجر القيمة الكاملة للمتأخرات الواقعة على عاتقه قبل هذه الدفعة.

لن يحتاج `pdfDocs.ts` إلى تعديل — نفس الحقول الحالية كافية، فقط نغيّر القيمة المُمرّرة.

## ما لن يتغيّر
- لا تعديل على قاعدة البيانات.
- لا تعديل على منطق الحفظ ولا على عدد الصفوف المُدخلة.
- لا تعديل على `pdfDocs.ts` (الحقول موجودة).
- البطاقة الحالية "تفاصيل المتأخرات" (تفصيل شهر-بشهر مع خيار التحصيل) تبقى كما هي بدون تغيير.

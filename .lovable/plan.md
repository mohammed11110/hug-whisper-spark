## الهدف
صفحة جديدة **"التحصيل الشهري" (Monthly Collection)** توضّح لكل شهر:
- إجمالي الإيجار المتوقّع.
- إجمالي المستلم فعلاً.
- نسبة التحصيل.
- قائمة **المستأجرين الدافعين** (اسم + الوحدة + المبنى + المبلغ).
- قائمة **المستأجرين المتأخرين** (اسم + الوحدة + المبنى + المبلغ المستحق).

---

## التغييرات

### 1. صفحة جديدة `src/pages/MonthlyCollection.tsx`
- **منتقي شهر**: أزرار للأشهر الـ12 الماضية + الحالي (sliding chips).
- **بطاقات KPI** للشهر المختار:
  - إجمالي المستحق (مجموع إيجارات الوحدات المؤجَّرة شهرياً).
  - إجمالي المستلم (مجموع `payments` التي `period_start` ضمن الشهر).
  - المتبقي = المستحق − المستلم.
  - نسبة التحصيل %.
  - عدد دافعين / متأخرين.
- **قسم "✅ دافعون"**: قائمة موسعة قابلة للطي. كل بند: اسم المستأجر · رقم الوحدة · اسم المبنى · المبلغ · تاريخ الدفع.
- **قسم "⚠️ متأخرون"**: نفس الصيغة لكن بلون burgundy، مع زر "تحصيل سريع" يفتح حوار الدفع المُجهَّز بالشهر المختار.
- **زر CSV**: تصدير القائمتين.

منطق التحديد:
- **دافع** = الوحدة لها payment واحد على الأقل بـ `period_start` ضمن الشهر (مجموع المبالغ ≥ rent_amount). إن كان المجموع < rent_amount → "دفع جزئي" (فئة فرعية ضمن المتأخرين).
- **متأخر** = وحدة مؤجَّرة (tenant_name موجود) + الشهر ≥ contract_start + لا توجد دفعة كافية لذلك الشهر.
- يتم استثناء الوحدات الشاغرة وأي وحدة بدأ عقدها بعد الشهر المختار.

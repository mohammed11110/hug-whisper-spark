
# خطة تجهيز "أملاكي" للنشر على App Store

سأنفّذ كل ما يمكن عمله داخل المشروع، ثم أعطيك دليلاً واضحاً لخطوات Apple التي تتطلب جهازك وحسابك.

## ما سأنفّذه أنا داخل المشروع

### 1. ميزة حذف الحساب (شرط إلزامي من Apple)
- إضافة قسم "حذف الحساب" في صفحة الإعدادات
- نافذة تأكيد بكتابة "حذف" + كلمة المرور
- Edge Function آمنة تحذف:
  - بيانات المستخدم من كل الجداول (مبانٍ، وحدات، مستأجرين، مدفوعات…)
  - حساب المصادقة من Auth
- تسجيل خروج تلقائي بعد الحذف

### 2. إضافة Capacitor وتجهيز إعدادات iOS
- تثبيت `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`
- إنشاء `capacitor.config.ts` بـ:
  - `appId: app.lovable.c6fcf97d71d44c46b75687a26fc2bf21`
  - `appName: Amlaki`
  - رابط hot-reload للتطوير
- إعداد Splash Screen بألوان أملاكي (sage/cream)

### 3. تجهيز الأيقونات وشاشة البداية
- توليد أيقونة 1024×1024 رئيسية بهوية أملاكي
- توليد Splash Screen مع الشعار

### 4. تحسينات إلزامية لقبول Apple
- صفحات سياسة الخصوصية والشروط (موجودة) — مراجعة الروابط داخل التطبيق
- إضافة رابط "حذف الحساب" مرئي وواضح
- إخفاء Lovable badge في النسخة المنشورة

### 5. ملف تدقيق نهائي (Checklist)
- ملف `APP_STORE_CHECKLIST.md` يحوي:
  - نصوص متجر Apple (عربي + إنجليزي): العنوان، الوصف، الكلمات المفتاحية، ما الجديد
  - مقاسات لقطات الشاشة المطلوبة
  - حساب اختبار للمراجعة
  - تصنيف العمر والفئة (Business/Finance)

## ما تنفّذه أنت بعد ذلك (لا أستطيع عملها)

1. تصدير المشروع إلى GitHub (زر Export في Lovable)
2. `git clone` المشروع على جهاز Mac
3. `npm install` ثم `npx cap add ios` ثم `npx cap sync`
4. فتح المشروع في Xcode
5. حساب Apple Developer (99 USD/سنة)
6. رفع البناء عبر Xcode إلى App Store Connect
7. ملء معلومات المتجر (سأجهّزها لك جاهزة) ولقطات الشاشة
8. إرسال للمراجعة

## ملاحظات مهمة
- بدون جهاز Mac لا يمكن البناء لـ iOS — البديل خدمة سحابية مثل **Codemagic** أو **Ionic Appflow** (~30-50 USD/شهر)
- ميزة حذف الحساب **شرط رفض** عند Apple إن لم تكن موجودة
- أول مراجعة تستغرق 1-3 أيام عادة

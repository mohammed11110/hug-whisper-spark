## المشكلة

عند تحميل ايصال الاستلام أو عقد الإيجار لبعض المستأجرين فقط، يخرج ملف PDF كصفحة بيضاء فارغة، بينما يعمل بقية المستأجرين بشكل سليم.

## السبب الجذري المرجّح

في `src/lib/downloadHTMLAsPDF` نستخدم `html2canvas` مع:
- `allowTaint: false` + `useCORS: true`
- `foreignObjectRendering: true` تلقائياً عند وجود نص عربي (وهي حالة كل المستأجرين عملياً)

عندما يحتوي قالب العقد/الإيصال على شعار العلامة التجارية (`brand.logo`) كرابط خارجي أو رابط Supabase Storage بدون CORS مناسب:
- مع `foreignObjectRendering: true` المتصفح لا يحمّل الصور الخارجية داخل `<foreignObject>` → النتيجة Canvas فارغ تماماً (صفحة بيضاء).
- مع المسار البديل (catch) قد تتلوث الـ canvas أيضاً وتفشل بصمت.

ولهذا تظهر المشكلة فقط لمستأجرين معينين: هؤلاء يستخدمون قالب فيه شعار، أو شعار مرفوع من جهاز معين/مصدر مختلف عن البقية، أو حقل اسم/بيانات يحتوي محرف غير قابل للتحويل (نادر).

## الخطة

1. **تحويل الشعار إلى Data URL قبل التصيير**
   - في `downloadHTMLAsPDF` قبل استدعاء `html2canvas`، نلتقط كل `<img>` داخل الحاوية ونحوّل مصدرها إلى `data:image/...;base64,...` عبر `fetch` + `FileReader`.
   - إن فشل التحميل لأي صورة (مثلاً 404 أو CORS)، نستبدلها بصورة بديلة شفافة 1×1 ونكمل التصيير بدلاً من الفشل الكامل.

2. **كشف الصفحة البيضاء وإعادة المحاولة**
   - بعد توليد الـ canvas، نتحقق سريعاً إن كانت كل البكسلات بيضاء (عبر عينة من `getImageData`).
   - إذا كانت فارغة → نعيد المحاولة بدون `foreignObjectRendering` ومع `allowTaint: true`.
   - إذا بقيت فارغة → نعرض `toast.error` عربي/إنجليزي واضح بدل تنزيل ملف فارغ.

3. **تحصين قالب العقد**
   - التأكد أن `buildLeaseHTML` يتعامل مع `data.brand.logo === null/undefined` (موجود مسبقاً عبر `logo-fallback`، نتأكد فقط أنه لا يولّد `<img src="">` فارغ).

4. **سجل تشخيصي خفيف**
   - إضافة `console.warn` يحتوي اسم المستأجر/الإيصال + مصدر الشعار + سبب الفشل، لتسهيل التتبع مستقبلاً دون إزعاج المستخدم.
